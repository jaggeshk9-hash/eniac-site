# 🍎 ENIAC – Apple Products & Accessories Store

## 🛍️ About the Project

**ENIAC** is a **front-end e-commerce website** designed for showcasing and browsing Apple products and accessories.

The website provides a clean, simple, and responsive shopping interface where users can view different products along with their prices.

## ✨ Features

* 🍎 Apple products and accessories showcase
* 📱 iPhone and accessory products
* 🎧 AirPods section
* ⌚ Apple Watch straps
* 🛒 Shopping cart interface
* 🔍 Search icon
* 📂 Product category navigation
* 📧 Newsletter subscription
* 📞 Contact section
* 💳 Payment information
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* 🌐 **HTML5** – Website structure
* 🎨 **CSS3** – Styling and layout
* 📐 **W3.CSS** – Responsive design
* ⚙️ **JavaScript** – Interactive elements
* ⭐ **Font Awesome** – Icons
* ✍️ **Google Fonts** – Typography

## 🎯 Purpose

The main purpose of this project is to create a **simple, attractive, and responsive online store interface** for Apple products and accessories.

> 📌 This project is developed for **educational and front-end web development purposes**.
